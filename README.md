# Hello World!

This script prints "Hello World!" in your terminal!

To run it, execute the following command:

```bash
curl -fsSL https://raw.githubusercontent.com/ProPlat28/Hello-World-in-Shell/refs/heads/main/HelloWorld.sh | bash
```

This only works on Linux and macOS. If you want to do it on Windows, install [Git](https://git-scm.com/install/windows/). After that, do the same command than Linux and macOS, and it normally should work!
